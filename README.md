# Birthday Arc

A static, GitHub-Pages-friendly birthday website.

## Personalize
Open `index.html` and replace:
- `[HER NAME]`
- `[NAME]`
- `[AGE]`
- `[MEMORY TITLE]`
- the memory descriptions
- the special ability

No backend is required.

## Deploy free
Create a GitHub repository, upload `index.html`, then enable GitHub Pages under Settings → Pages → Deploy from branch.
